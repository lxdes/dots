** Installation
 Run the Fedora installer from a TTY or an existing minimal X session:
 #+BEGIN_SRC bash
 git clone https://codeberg.org/lxde/dots.git ~/nux
 cd ~/nux
 ./install.sh
 #+END_SRC

 The installer installs full Xorg and replaces its server/input packages
 with XLibre, enables the Quickshell, XLibre, xcolor, and WezTerm nightly
 COPRs plus Terra and RPM Fusion, then installs Steam, QEMU with guest
 graphics/SPICE support, vm-curator, Quickshell, Emacs, WezTerm, Fastfetch,
 and SDDM with its Breeze theme through RPM packages. QEMU guest services
 are enabled automatically when the installer detects a virtual machine.
 Home Manager installs the remaining Nix packages. Use
 =./install.sh --skip-doom= to omit Doom.
 The older manual notes are kept in [[file:install.org][install.org]].
