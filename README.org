** Stack
- *Distro*: [[https://fedoraproject.org/][Fedora]]
- *System Packages*: DNF
- *User Environment*: [[https://nixos.org/download/#download-nix][Nix]] and [[https://github.com/nix-community/home-manager][Home Manager]]
- *Window Manager*: [[https://github.com/baskerville/bspwm][bspwm]]
- *Desktop Shell*: [[https://quickshell.org/][Quickshell]]
- *Display Server:* [[https://github.com/x11libre/xserver][XLibre]]
- *Editor*: [[https://github.com/doomemacs/core][Doom Emacs]]
- *File Manager*: PCManFM and [[https://github.com/alexluigit/dirvish][Dirvish]]
- *Terminal*: [[https://wezterm.org/][WezTerm]]
- *Shell*: [[https://github.com/zsh-users/zsh][Zsh]] & [[https://ohmyz.sh/][Oh My Zsh]]
- *Session*: Xinit

** Hosts
Machine-specific configuration lives under =hosts/=. Shared Home Manager
modules remain under =modules/=.

- =hosts/base.txt=: Fedora packages installed on every host
- =hosts/<profile>/packages.txt=: Fedora packages for one host
- =hosts/<profile>/default.nix=: Home Manager modules and display settings
- =hosts/<profile>/displays.sh=: xrandr layout for that host
- =hosts/<profile>/install.sh=: one-time Fedora bootstrap

Available profiles:

- =generic=: detects =$USER= and =$HOME= and does not depend on the hostname
- =forda=: desktop profile for the Ryzen 7 5800X and Radeon RX 7600 machine
- =vm=: QEMU/SPICE guest profile

If no directory matches =hostname -s=, bspwm uses the generic automatic display
layout.

** Installation
*** Generic Fedora Minimal
The generic profile is the best starting point for a new machine and works with
Fedora's default hostname.

#+BEGIN_SRC bash
sudo dnf install -y git
git clone https://codeberg.org/lxde/dots.git "$HOME/nux"
cd "$HOME/nux"
./hosts/generic/install.sh
sudo reboot
#+END_SRC

After reboot, log in on a TTY and start bspwm:

#+BEGIN_SRC bash
startx
#+END_SRC

*** Known Hosts
Use a hardware-specific installer when its package and driver selection matches
the machine:

#+BEGIN_SRC bash
./hosts/forda/install.sh
./hosts/vm/install.sh
#+END_SRC

The =forda= and =vm= profiles currently use the =array= account. The =generic=
profile detects the account running the installer.

*** Bootstrap Actions
Each installer:

- enables the Quickshell, XLibre, xcolor, and WezTerm COPR repositories
- installs =hosts/base.txt= and the selected host's =packages.txt=
- installs Xorg first and replaces it with XLibre
- installs the host's physical or virtual graphics drivers when applicable
- enables the Nix daemon and flakes
- sets Zsh as the login shell
- activates the selected Home Manager profile
- installs Doom Emacs

Fedora package manifests are intended for initial setup. Normal Home Manager
switches do not run DNF.

*** Home Manager
Switch an existing profile manually:

#+BEGIN_SRC bash
home-manager switch --flake .#forda
home-manager switch --flake .#vm
home-manager switch --impure --flake .#generic
#+END_SRC

The generic profile requires =--impure= so Home Manager can read =$USER= and
=$HOME=.

Supplemental manual setup notes remain in [[file:install.org][install.org]].
